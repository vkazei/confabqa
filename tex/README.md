`paper_confabqa.tex` is a clean, hand-editable LaTeX source of the ConfabQA paper; all package loading and styling live in `preamble.tex` (loaded via `\input`). Figures are bundled under `tex/figures/`; references live in `refs.bib` (BibTeX + natbib, `plainnat` author-year).
Compile with `xelatex paper_confabqa.tex; bibtex paper_confabqa; xelatex paper_confabqa.tex; xelatex paper_confabqa.tex`. TeX-Live-shipped fonts (TeX Gyre Termes/Heros, DejaVu Sans Mono, Fandol) are loaded by filename, no font installation needed. For arXiv, upload the generated `paper_confabqa.bbl` alongside the sources.
NOTE: `paper_confabqa.tex` is the source of truth for the paper. `../reproduce.sh arxiv` packages this directory into `arxiv_upload.tar.gz`; `../reproduce.sh full` rebuilds and copies the PDF to the repo root.
